# AgriSetu – Farmer's Digital Marketplace (prototype)

Open `index.html` in any browser. No install or server needed.

Files: index.html (page), styles.css (styling), app.js (all logic).

Portals: Farmer, Buyer, Transporter, FPO.
Features: KYC (transporter incl. driving licence proof), order approval by farmer with transport choice,
distance-based delivery charge, mandi price comparison, escrow payment + thank-you/payment-done screens,
FPO member management, reviews in every portal, English/Hindi.

Demo notes: OTP is 1234; mandi rates, UPI escrow and UIDAI/Parivahan verification are simulated.
Data is stored in the browser (localStorage). Use the Reset tab to clear it.
Note: the "download" buttons use a Claude-specific helper when available and fall back to normal browser downloads.
